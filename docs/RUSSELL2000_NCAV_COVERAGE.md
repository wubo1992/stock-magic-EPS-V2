# Russell 2000 NCAV 深度价值策略 — 数据覆盖报告

## 1. 项目目标

实现巴菲特早期"捡烟蒂"投资策略的系统化回测，基于格雷厄姆 NCAV 公式：

```
NCAV = 现金 + 0.75 × 应收账款 + 0.5 × 存货 - 流动负债
```

筛选标准：**P/NCAV < 2.0**（价格相对于净流动资产价值被低估）

## 5. 数据获取限制说明

### 5.1 为什么 NCAV 候选只有 109 只？

NCAV 公式要求：
- 现金 > 0
- 流动负债 > 0
- NCAV = 现金 + 0.75×应收账款 + 0.5×存货 - 流动负债 > 0

大部分上市公司流动负债高于流动资产，天然不满足 NCAV > 0 的条件。这是格雷厄姆"捡烟蒂"策略的核心筛选逻辑。

### 5.2 为什么只有 7 只深度价值股？

从 109 只 NCAV > 0 的股票中，还需要：
- 有市值数据
- 有价格数据
- P/NCAV < 2.0

同时满足以上条件只剩下 7 只。

### 5.3 能否提高覆盖率？

**已接近极限**：
- SEC 覆盖率 96.7% 已无法再提高（剩余 3.3% 公司已退市或无 SEC 备案）
- NCAV 候选少是策略本身的筛选逻辑，不是数据问题
- 深度价值股少是因为 P/NCAV < 2.0 是非常严格的估值标准
