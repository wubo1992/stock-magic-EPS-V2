# Weinstein Stage 2 分析策略说明

> **策略ID**: `v_weinstein`
> **灵感来源**: Stan Weinstein《多空操作秘籍》
> **适用场景**: 中长期趋势跟踪，Stage 2 主升浪

---

## 📚 策略哲学

**核心理念**："只在 Stage 2（上涨阶段）买入，持有到 Stage 4（下跌阶段）卖出。"

Stan Weinstein 的阶段理论：
- **Stage 1**：底部筑底（不买）
- **Stage 2**：上涨阶段（买入）← 我们只在这个阶段操作
- **Stage 3**：顶部整理（卖出）
- **Stage 4**：下跌阶段（空仓）

**简化版本**：我们的策略只检测 Stage 2，不判断其他阶段。

---

## 🎯 核心特点（与其他策略的差异）

### 1. 无相对强度 RS

```
v1_plus: RS ≥ 70%（必须有）
v_weinstein: 无 RS 过滤  ← 完全不看
```

**Weinstein 的逻辑**：
- 不需要跑赢大盘
- 只要股票处于 Stage 2，就值得买入
- 趋势比相对强度更重要

---

### 2. 无 VCP 形态

```
v1_plus: 必须有 VCP 形态
v_weinstein: 无 VCP 检测  ← 完全不看
```

**为什么不用 VCP？**
- Weinstein 关注的是"阶段"而非"形态"
- 整理形态可以是 VCP、杯柄、三角形，不重要
- 重要的是 SMA150 的趋势方向

---

### 3. 只用 SMA150（30 周均线）

```
v1_plus: SMA50 > SMA150 > SMA200（三条均线）
v_weinstein: SMA150（一条均线）← 与 Zanger 相同
```

**Weinstein 的核心工具**：
- SMA150 ≈ 30 周均线（150 天 ≈ 30 周）
- 这是 Weinstein 最看重的指标
- 只要看 SMA150 的方向，就能判断阶段

---

### 4. Stage 2 确认条件

```
Weinstein Stage 2 定义：
1. SMA150 正在上升（趋势向上）
2. 价格在 SMA150 之上（确认阶段）
3. 价格突破整理区（入场时机）

我们的实现：
1. SMA150(当前) > SMA150(30天前)  ← 趋势向上
2. 当前价格 > SMA150              ← 价格在均线上方
3. 突破过去 30 日最高价            ← 入场信号
```

**重要**：我们只检测 Stage 2 入场，不检测 Stage 3/4 出场。

---

### 5. 信号频率最高

```
v1_plus: 6.8 个/月
v_zanger: 13.1 个/月
v_weinstein: 28.5 个/月  ← 最高
```

**为什么信号这么多？**
- 条件极简：只有 SMA150 + 突破 + 放量
- 无 RS、无 VCP 过滤
- 很多股票满足 Stage 2 条件

---

### 6. 中长期持有

```
v_zanger: 时间止损 10 天
v1_plus: 时间止损 20 天
v_weinstein: 时间止损 30 天  ← 最长
```

**Weinstein 的理念**：
- Stage 2 是中长期趋势
- 给股票更多时间发展
- 不追求快进快出

## 🎯 买入条件（极简化）

### 只需 4 个条件

1. **SMA150 上升**
   ```
   当前 SMA150 > 30 天前 SMA150
   说明：30 周均线向上，Stage 2 确认
   ```

2. **价格在 SMA150 之上**
   ```
   当前价格 > SMA150
   说明：股票在上升趋势中
   ```

3. **突破整理区**
   ```
   当前价格 > 过去 30 日最高价 × 1.005
   说明：创近期新高，入场时机
   ```

4. **放量确认**
   ```
   当前成交量 ≥ 20 日均量 × 1.5
   说明：大资金入场
   ```

**就这么简单！** 无 RS、无 VCP、无 SMA50/SMA200。

## 📚 Weinstein 的阶段理论

### 完整的四阶段模型

**Stage 1：底部筑底**
```
特征：
- SMA150 横盘或缓慢下降
- 价格在 SMA150 上下波动
- 成交量萎缩

操作：不买
```

**Stage 2：上涨阶段** ← 我们的买入点
```
特征：
- SMA150 开始上升并持续向上
- 价格在 SMA150 之上
- 高点不断创新高
- 成交量放大

操作：买入并持有
```

**Stage 3：顶部整理**
```
特征：
- SMA150 上升斜率减缓
- 价格在 SMA150 附近震荡
- 成交量萎缩

操作：卖出
```

**Stage 4：下跌阶段**
```
特征：
- SMA150 开始下降
- 价格在 SMA150 之下
- 低点不断创新低

操作：空仓
```

### 四阶段判定：`data/stage.py`

`data/stage.py::compute_stage(df)` 把上面四段文字变成了代码。

**判据不是本项目自己拟的，是逐行移植自参考实现的生产引擎**：

```
/Users/wubo/Desktop/codes/Stan Weinstein stage analysis/weinstein/classical.py
规则版本：WEINSTEIN-STRUCTURE-1.3
```

参考实现跑在**周线**上，所以本模块先把日线重采样成周线（`W-FRI`），再跑同一套状态机。
移植后与参考实现在真实行情上**逐票比对过**（主阶段 / 子阶段 / 均线斜率 / 价格位置 / 持续周数全部一致）。

**全池 parity 实测**（2026-11-10，`data/cache/` 全部 17,835 个 pkl）：

| 结果 | 数量 | 说明 |
|------|------|------|
| 完全一致 | **10,126** | stage / substage / 均线斜率 / 价格位置 / 持续周数 全部相同 |
| 不一致 | **12** | **全部**是量能口径保护生效的票（见下面第 3 个坑） |
| 跳过 | 7,696 | 周线不足 60 根，或 pkl 不是行情 DataFrame |
| 报错 | 1 | **参考实现**崩了（`VSTD`：某根 close=0 → `_build_segments` 除零）；本项目正常返回 4/4B |

| 输入 | 口径 |
|------|------|
| 30 周均线 | MA30，当前 MA30 相对 4 周前的变化率；±0.30% 视为走平 |
| 价格位置 | 收盘价相对 MA30 的偏离百分比 |
| 区间结构 | 前 26 周的最高/最低价（**不含本周**），判断突破 / 跌破 / 区间位置 |
| 高低点结构 | 最近 4 周 vs 此前 4 周的更高/更低高点、更低低点 |
| 前序阶段 | 区分「筑底 vs 顶部」「底部失败」「顶部向上突破」「V 形过渡」 |

**主阶段状态机**（移植自 `classical._assign_classical_stages`）：

| 当前阶段 | 转换条件 |
|---------|---------|
| 初始 | 结构向上 → Stage 2；结构向下 → Stage 4；其余按 26 周涨跌定 Stage 1 / Stage 3 |
| Stage 1 | 只有突破**自身底部阻力**才进 Stage 2；只有跌破**自身底部支撑**才回 Stage 4 |
| Stage 2 | 向下且（跌破 26 周支撑 / 13 周新低 / 更低低点）→ Stage 4；跌破均线且（更低高点 / 更低低点 / 均线走平）→ Stage 3；均线走平且 13 周内穿越 ≥2 次 → Stage 3 |
| Stage 3 | 向下且（跌破支撑 / 13 周新低 / 更低低点）→ Stage 4；向上且突破 26 周阻力 → Stage 2 |
| Stage 4 | 向上且突破 26 周阻力 → Stage 2；站回均线且（更高低点 / 均线走平）→ Stage 1 |

**A/B 子阶段**（Weinstein Global Trend Alert 映射，移植自 `classical.classify_classical_substage`）：
1A/1/1B、2A/2/2B、3A/3/3B、4A/4/4B/4B-。

四个容易踩的坑：

1. **主阶段只用结构，不用动量分数**。参考实现里被废弃的旧引擎（`analysis.py`）用
   13 周动量分数、连续三周确认、固定八周最短阶段、−8% 偏离自动跳级 —— 这四样**一律不用**。
2. **窗口按交易日算，不是行数**。行情 pkl 里同一天有两根 bar（合并量 + IEX），
   所以 `compute_stage` 内部先调 `data/daily_bars.dedup_daily_bars` 再重采样周线。
3. **量能口径不能跨源比较**。去重后留下的是 IEX 那一根，量只有合并量的 1/20~1/50；
   跨口径比量比会让最近几周假性暴跌、误触发 Stage 4B 的「缩量」判据。
   所以每周记一个主导口径，量比只跟**同口径**的历史周比（样本不足 4 个则不算）。
   **这是与参考实现唯一的口径差异**（全池 17,835 个 pkl 里 12 只受影响）：
   参考实现会把这 12 只判成 `4B`（量比 0.01~0.03），本项目判成 `4`（同口径量比 1.17~2.6）——
   前者是行情源切换造成的假「缩量」，不是真的缩量。
4. **周线不足 60 根就判不了**（参考实现的硬性要求）→ 返回 `stage=None`，报告显示「—」，不猜。

**周线未收完时**（本周还没走完）最新一根周线是「发展中」的暂定读数。呈现规则：

- 报告表格里**只有当这一周把阶段翻掉了**（与上一根完整周线的主阶段不同）才标「待定」，
  括号里写出上一完整周的读数 ——
  例：`Stage 1 筑底期 · 1A（待定，上周 Stage 4 下跌期 · 4B-）`；
- 没翻掉就**不标** —— 整张表每行都挂一个「发展中」等于没信息；
- 理由句里一定写清楚是哪种情况：
  「本周尚未收完，但与上一完整周结论一致：Stage 3 / 3」
  或「本周尚未收完，这一周把阶段从 Stage 4 翻成了 Stage 1」。

参考实现的口径是「发展中结论可变化，同时显示上一完整周」；这里按「可变化」落地成
「只有真变了才提示」，避免半个交易日的价格波动就报一个假预警。

判定用的是**当前**状态（最新一根 K 线），不是信号触发那天的状态 ——
信号触发时必然是 Stage 2（那是入场条件本身），那一列的价值全在事后跟踪。
